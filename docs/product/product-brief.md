# 产品简述

## 产品定义

帮助家庭持续回答三个问题：家里有什么、今天适合做什么、需要再买什么。

产品闭环：

```text
家庭约束 → 食材库存 → 一餐决策 → 烹饪执行 → 库存变化 → 采购补充 → 反馈学习
```

## 目标用户

优先服务每周在家做饭多次、由一名主要协调者负责买菜或做饭的 2–5 人家庭。其他成员通过报餐、投票、购物清单和口味反馈低成本参与。

## 核心价值

- 减少“今天吃什么”的决策时间。
- 优先使用临期和剩余食材，降低浪费。
- 根据人数、时间、厨艺和设备提供可执行方案。
- 自动汇总缺少食材并避免重复购买。
- 形成家庭长期口味与消费习惯，但允许成员控制个人信息。

## 产品原则

- 首次录入少量食材即可产生价值，不要求完整盘点冰箱。
- 推荐以结构化菜单卡片呈现，对话用于补充、纠错和解释。
- 默认给出多个目标不同的方案，例如零采购、最省时和最符合口味。
- 不完整库存仍可使用，但必须标明结果基于已知信息。
- 商业推荐不能破坏“优先使用现有食材”的可信度。

## 北极星指标

每个活跃家庭每周通过系统推荐并实际完成的餐次。
