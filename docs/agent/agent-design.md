# Agent 设计

## 定位

Agent 是自然语言入口和任务编排者，不是库存、食品安全或权限的事实源。

## 初始意图范围

1. 查询家中库存和临期项目。
2. 按人数、时间、厨艺和采购限制推荐菜单。
3. 查询某道菜还缺什么。
4. 记录买入、开封、使用或丢弃。
5. 生成和更新共享购物清单。

## 推荐流程

```text
理解请求
  → 获取参与者、库存批次和厨房条件
  → 执行硬约束过滤
  → 检索结构化菜谱
  → 计算临期、库存覆盖、时间、难度和偏好评分
  → 在允许范围内做替代或份量调整
  → 再次执行安全与约束校验
  → 输出菜单、缺少项、假设和推荐理由
```

## 工具边界

计划提供的确定性能力包括：查询库存、变更库存、读取家庭约束、搜索菜谱、检查过敏和禁忌、计算有效期限、缩放份量、计算缺少项和更新购物清单。

写操作应满足：

- 具有幂等键；
- 经过服务端权限校验；
- 在识别结果或用户意图不确定时先确认；
- 保存操作者、来源和变更前后状态；
- 可撤销或通过纠正事件恢复。

## 记忆边界

家庭共享事实、成员私有信息、单次会话条件和行为推断分开存储。只有用户明确确认的信息可以升级为长期硬约束；行为推断只能作为低置信度软偏好并允许撤销。
