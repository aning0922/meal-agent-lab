# 设计资料

这里保存信息架构、用户旅程、低保真流程、视觉规范和跨平台差异说明。可编辑源文件放入 `assets/mockups/`，导出图片放入 `assets/images/`。

当前信息架构见 [information-architecture.md](information-architecture.md)，详细业务流程见 [../product/core-user-flows.md](../product/core-user-flows.md)。

当前低保真原型的页面清单、验证目标与评审任务见 [low-fidelity-prototype.md](low-fidelity-prototype.md)。

独立评审结论见 [low-fidelity-prototype-review.md](low-fidelity-prototype-review.md)，
P0 页面统一状态与恢复规则见 [p0-page-state-baseline.md](p0-page-state-baseline.md)。

优先设计的页面：

1. 登录恢复、创建家庭与邀请成员。
2. 首次录入少量食材，以及库存搜索、批次详情与历史。
3. 今日首页：临期提醒、参与者、时间、建议组合与可选菜。
4. 菜单详情与并行烹饪步骤。
5. 共享购物清单。
6. 同页完成状态与库存确认。
7. “我的”、隐私数据控制和 Agent 二级任务页。

设计时优先减少输入负担，并为所有识别结果提供清晰的确认和纠错入口。
