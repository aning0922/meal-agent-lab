# 架构决策记录

ADR 用于记录影响范围大、迁移成本高或存在明显权衡的技术决定。

## 命名

使用递增编号和短标题，例如：

```text
0001-first-client-platform.md
0002-cross-platform-framework.md
0003-backend-runtime.md
```

状态使用 `Proposed`、`Accepted`、`Superseded` 或 `Rejected`。新决策替代旧决策时保留旧文件并相互链接。
