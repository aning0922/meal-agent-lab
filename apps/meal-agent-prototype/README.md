# Meal Agent 低保真原型

用于评审 Meal Agent P0 核心闭环的可点击低保真原型。它不是正式客户端，也不连接真实账号、库存或同步服务。

## 覆盖流程

```text
首次引导 → 首批食材 → 今天吃什么 → 建议组合与可选菜 → 共享采购
        → 已买待入库 → 开始做饭 → 完成状态 → 库存扣减与剩菜回库
```

库存临期、家庭设置和上下文 Agent 入口与主闭环相连。桌面视图在小程序参考画布两侧提供页面目录、当前验证问题、页面状态模拟和评审任务；窄屏视图保留核心产品界面，并从顶部“页面与验证点”打开评审目录。

## 评审重点

1. 首次使用是否能在不填精确重量和日期的情况下完成 5 项食材录入。
2. 用户是否理解建议菜品数量，并能快速增减可选菜、看懂整餐变化。
3. “已买”和“已入库”两个状态是否容易区分。
4. 做饭完成后，用户是否理解库存仍需确认，并能调整、排除、处理冲突和保存剩菜。
5. 每个页面在空、加载、未知、失败、无权限、部分成功、冲突、安全阻断、重复提交和恢复状态下是否仍然可信。
